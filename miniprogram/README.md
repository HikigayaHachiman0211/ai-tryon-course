# 微信小程序

这是平台的原生微信端，使用 TypeScript、WXML、WXSS。它调用主站 FastAPI 和虚拟试穿工作台的接口。

## 页面

| 页面 | 主要功能 |
| --- | --- |
| 推荐 | 填写偏好、选择照片或演示人台，查看推荐和五维评分 |
| 商品目录 | 搜索、筛选商品，进入详情或试穿 |
| 试穿 | 生成试穿图，或将图片送入 01Router 视频流程 |
| AI 导购 | 文字对话、偏好回填、语音识别、朗读和通话 |
| Style Lab | 查看单品匹配度、评分拆解和搭配建议 |
| 历史 | 查看和恢复推荐、单品分析记录 |
| 设置 | 切换中英日三语、选择服务地址并诊断连接 |

## 本地联调

1. 按仓库根目录说明启动主站 API（`127.0.0.1:8000`）和工作台（`127.0.0.1:8080`）。如需配置第三方模型，同时启动后台。 [本地启动说明](../README.md#本地启动)
2. 在微信开发者工具里导入本目录 `miniprogram/`。使用测试环境，或填入自己的 AppID。用模拟器连接本地 HTTP 服务时，可在工具的本地设置中关闭开发域名校验。
3. 打开小程序 **设置**，选择 **本地手动端口（8000 / 8080）**，运行连接诊断。若工作台已在 8082，可选择对应的本地预设。

## 真机联调

真机使用自己的小程序 AppID、可访问的 HTTPS 域名，并在微信公众平台配置相应的 request、uploadFile 和 downloadFile 合法域名。Azure 与阿里云的 Caddy 模板可在同一 HTTPS 域名下，将 `/mp-tryon` 转发给试穿工作台。在设置页选择云端统一反代并填入域名即可使用该配置。 [Azure 配置](../deploy/azure/Caddyfile)、[阿里云配置](../deploy/aliyun/Caddyfile)

图片、视频和语音功能须在服务端配置供应商。视频参考图的访问要求见 [01Router 配置](../tryon-workbench/VIDEO_GENERATION_SETUP.md)。
