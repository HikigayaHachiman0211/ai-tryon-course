# 01Router 试穿视频

试穿工作台新增“试穿视频”区域。可从页面上方进入，或在图片试穿结果下点击“用此结果生成视频”。支持上传图片、填写公开图片链接、动作预设、实时模型与供应商选择、详细参数、费用预估、任务恢复、取消、播放及下载。中文、英文、日文均可使用。

## 启用

1. 在管理后台进入 **AI 模型设置 → 试穿视频**。
2. 选择正式 API `https://01router.com/api/v1`，保存 01Router 项目 API Key 并开启视频功能。
3. Project ID 可留空；填写时必须与密钥所属项目一致。留空读取平台完整目录，填写后读取对应项目的模型别名、参数和指定供应商。
4. 设置请求超时、全站每分钟与每日生成上限。默认分别为 60 秒、3 次/分钟、20 次/日。限额由所有访客共享，每日按美国太平洋时间零点重置。
5. 点击“测试已保存连接”。测试只读取任务列表，不生成视频。配置约 15 秒内生效。

密钥通过现有管理端加密服务保存，必须与工作台使用同一 `FERNET_SECRET_KEY` 和管理配置数据库。工作台通过 `AI_CONFIG_DATABASE_URL` / `DATABASE_URL` 读取配置。管理员显式关闭功能或保存的密钥无法解密时，不通过环境变量绕过该状态。

尚未初始化后台记录时，也可使用服务端环境变量：

```text
ROUTER01_ENABLED=true
ROUTER01_BASE_URL=https://01router.com/api/v1
ROUTER01_API_KEY=<在服务端秘密存储中配置>
ROUTER01_PROJECT_ID=<可选>
```

不要把上述密钥配置为 `VITE_*`。`https://01router.com/gateway` 是产品页面，API 使用 `/api/v1`。

## 图片和公网地址

推荐先生成满意的图片试穿结果，再用它作为视频首帧。模型也可提供尾帧、多参考图、视频或音频输入，以实时目录为准。上传至工作台的图片会先验证访问权限，再生成有效期一小时的签名 URL 交给视频供应商，不公开整个上传目录。

供应商必须能够从公网访问图片。工作台运行于 `localhost` 时，可直接在图片参数中填入公开图片 URL；本地上传图只有在工作台具备公网可达地址时才能被供应商读取。反向代理后的应用可显式设置：

```text
ROUTER01_MEDIA_BASE_URL=https://your-public-tryon.example.com
```

此地址必须实际路由到当前工作台；仅填写一个域名不会自动发布本地服务。多实例需沿用项目已有的共享任务数据库、对象存储和固定媒体签名密钥配置。

## 模型与详细参数

模型、供应商和参数来自 01Router 实时目录，服务端缓存 60 秒，可通过按钮刷新。没有硬编码的固定视频模型名单。

选择供应商后，表单使用该供应商的参数定义；切换模型或供应商时清除不兼容参数，保留可用的提示词和参考图。表单支持文本、整数、数值、枚举、布尔值、单图、多图及其他目录定义的媒体字段，并显示原始参数名、说明、范围、默认值、字符和数量限制。

目录支持时可调整时长、分辨率、比例、首尾帧、音频、种子、帧率、负面提示词、参考视频等。界面不会为不支持某项能力的模型伪造设置。动作预设包括缓慢转身、自然行走、面料特写和棚拍展示。

报价通过公开 `/quote` 获取，输入变化后重新计算并忽略过期响应。列表按网关路由顺序显示，首项标明自动路由首选。显示的是网关报价，不含项目转售加价；最终费用以任务结果的结算为准。获得当前参数报价后才能点击生成。

## 任务与恢复

- 使用原生 `/generations` 异步协议，任务在外部供应商执行，不占用图片试穿队列。
- 本地 `workbench_video_tasks` 表保存访客归属、提交摘要、上游任务编号和结果；共用现有 `TASK_DATABASE_URL` / 数据库配置，在工作台启动时建表。
- 每次主动生成有唯一提交编号，服务端先持久化占位再联系上游。重复请求复用回执；同编号但不同参数返回冲突。
- 页面每 4 秒查询任务；服务端限制同一任务至少间隔 3 秒向上游查询。短暂网络错误按有界退避重试，30 分钟后暂停自动查询，可手动继续。暂停查询不会取消任务。
- 页面刷新后恢复最近任务。若提交响应丢失，先只读查找回执；未确认时禁止创建新提交编号，手动重试沿用原编号与原参数。
- 上游创建结果不明时标记“提交状态待确认”，不会自动重新生成，应在 01Router 控制台核对。
- 取消依赖供应商支持，网关不支持时会提示任务继续运行。已结束状态不会被较旧的轮询覆盖。
- 原生播放器支持播放；下载通过授权流式接口提供附件，支持有效期一小时的专用下载签名，单文件上限 512 MB。外部结果链接可能过期，应及时保存。

嵌入主站时使用访客任务令牌请求头兼容第三方 Cookie 限制。该令牌与服务器上的 01Router API Key 分离；浏览器不会接触 API Key。

## 本地接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/video/config` | 公开能力状态及私有访客会话，禁止缓存 |
| `GET /api/video/models` | 实时视频目录，可选 `refresh=true` |
| `POST /api/video/quote` | 所选模型、供应商和参数的费用预估 |
| `POST /api/video/tasks` | 生成，需要 `idempotency_key` |
| `GET /api/video/submissions/{key}` | 只读恢复提交回执 |
| `GET /api/video/tasks` | 当前访客最近 20 个任务 |
| `GET /api/video/tasks/{id}` | 查询任务 |
| `POST /api/video/tasks/{id}/cancel` | 请求上游取消 |
| `GET /api/video/tasks/{id}/download?index=0` | 下载自己的结果；也支持结果回执内的专用签名链接 |
| `GET/PUT /api/ai-config/video` | 管理端连接设置，需管理员登录 |
| `POST /api/ai-config/video/test` | 管理端只读连接检查 |

## 已验证范围

2026-11-15：工作台 Python 回归 58 项及 3 个子测试通过，JS 测试 6 项通过；管理员配置与现有图片中转配置回归 5 项通过；管理端新页面组件测试 2 项、类型检查与生产构建、三语言资源一致性检查通过。

隔离浏览器使用模拟模型与任务，验证了模型/供应商切换、默认值、预设、上传、图片结果转视频、过期报价丢弃、重复点击保护、刷新恢复、提交响应丢失后的同编号重试、原生播放、附件下载、取消，以及 1280px 桌面和 390px 手机的三语言界面。播放测试使用本地合成短片，不是实际 AI 视频。

当前执行环境访问公开模型 JSON 返回 403，未使用真实 API Key 或调用付费生成，因此真实供应商可用性、生成质量和实际扣费尚未验证。已有 OSS 存储测试因缺少可选 `alibabacloud_oss_v2` SDK 未运行；其余工作台测试均通过。保留原有 FastAPI 启动事件弃用警告。
