Google AI Studio 接口

Gemini API 密钥

这里可以保存一个默认的 Google AI Studio Gemini API 密钥。只有当你把生成通道切换到 Google AI Studio 接口 时，系统才会使用这里保存的密钥。

默认行为：
系统默认仍使用 Vertex AI API。这里保存的 AI Studio 密钥不会影响 Vertex 模式。

覆盖规则：
如果你在主面板填写了 API 密钥，本次请求会优先使用主面板中的密钥，覆盖这里保存的默认值。

费用提醒
Gemini API 与 Vertex AI 是两条不同的接入路径。不要默认认为你当前的 Vertex 或常规 GCP 额度会自动覆盖这部分调用。Google 官方明确说明：Google Cloud welcome credits 不能用于抵扣 Gemini API usage。请务必到生成该 AI Studio / Gemini API 密钥的项目里单独核对账单与配额。

本地反代 API

反代设置

用于接入本机 Antigravity / Gemini 兼容反代。启用后，自动模式会优先走这里配置的本地反代通道。

推荐默认值：
接口地址使用 http://127.0.0.1:8045，Flash 模型填 gemini-3.1-flash-image，Pro 模型填 gemini-3-pro-image。

认证说明：
后端会同时尝试发送 x-goog-api-key 和 Authorization: Bearer ...，兼容常见 Gemini 反代配置。

启动 API 反代教程
  1. 先打开 Antigravity Tools，在 API 反代 页面把端口设为 8045，然后点击 启动服务。
  2. 建议开启 访问授权，不要保持“开放”模式；复制里面的 API 密钥，填到上面的 反代 Token / API Key。
  3. 在 Antigravity 的 账号管理 页面确认账号不是“反代已禁用”，否则即使服务启动也不会参与调度。
  4. 在 Antigravity 的模型列表中确认实际可用模型名。优先填写 gemini-3.1-flash-image 和 gemini-3-pro-image；如果你的反代暴露的是别名，就按实际名称填写。
  5. 回到这里，填好 接口地址、Token、模型名后，先点 保存配置，再点 测试连接。测试成功后即可在主界面切换到 本地反代 或保留 自动 模式。
排错提示： 如果测试里 `contains_flash_model` 为否，但 `contains_pro_model` 为是，说明当前反代只暴露了 `gemini-3-pro-image`，这时请先把 Flash 模型名改成实际暴露的名字，或者先只使用 Pro。
